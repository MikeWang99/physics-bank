
# Pocket Cosmos — TIMBAD 物理题库评级与审核规范

> **用途**：供人工审核员或 AI 在审核**每一道物理题**时统一执行：验证题目质量 → 独立解题 → 给出 **L0–L7** 整体难度 → 逐项评定 **TIMBAD 六维难度（T/I/M/B/A/D，均为 0–2）** → 标注难点、数学工具、知识点及审核状态 → 输出可追溯的理由和结构化记录。
>
> **重要**：本文为 Pocket Cosmos 自定义的*运营评分规范*，不是 IGCSE、AP、BPhO、F=ma 或其他考试机构发布的官方难度标准；不宣称已通过统计信度或效度验证。必须通过锚定题与真实学生数据持续校准。

# 1. 使用目的与不可违反的原则

## 1.1 本体系回答三种不同的问题

| 问题 | 对应字段 | 不可混淆之处 |
|---|---|---|
| 题目整体有多难？ | `overall_level: L0–L7` | 供作业分层、难度筛选。L0 仅表示淘汰，不表示“比 L1 容易”。 |
| 题目具体难在哪里？ | `timbad: {T,I,M,B,A,D}` | 六个维度各 0–2；解释解题障碍，并不直接求和确定 L。 |
| 题目用来训练什么？ | `topic`, `subtopic`, `key_skills`, `primary_bottleneck`, `math_tools`, `prerequisites` | 用于给学生精准布置训练。 |

**题目本身的困难（Question Difficulty）与具体学生的错误（Student Error）必须分开记录。** 例如题目的 `M=2`，学生却因代数移项错误而失分：题目画像仍然是 M2，学生本次错误单独记录为 `error_tag=A`，不得更改题目难度画像来迎合学生错误。

## 1.2 比较难度时使用同一个参照前提

> **统一参照**：假设学生已经系统学习并正常掌握本题所需要的前置物理知识、常规数学工具和基础题型；但此前**没有见过这道具体题**，也**没有预先记住本题的专用技巧或答案**。判断这名学生在**独立、不受提示**条件下解决它的认知要求。

这意味着：

- 已学 `F=qvB` 的学生直接代入，可能是 L2；没学磁场的学生无法解答，不代表这道题是 L7。
- 使用微积分不自动加难度；一条需要创造性洞察的初等代数题，也可能是 L6/L7。
- 不按考试名、年份、题号、压轴位置、题干长度、图形复杂度、计算页数、作者声称的难度直接定级。
- **以题目要求的、前置条件允许的合理独立解法为准**。若有多个可行解法，优先考虑已掌握常规工具的学生较可能发现的**最简可靠解法**；不可用仅专家才知道的超巧妙解法把实际认知难度强行压低，也不能用故意冗长的解法抬高分数。
- 图像中的必要条件与题干文字具有同等效力。

## 1.3 三条基本原则

1. **先解后评**：在给出最终 L 评级前，至少应建立一条充分可靠的解题路线；必要时验算答案。
2. **定级与诊断分离**：`overall_level` 独立判断；TIMBAD 画像为证据而非机械计分器。
3. **可复核性**：每一个非零 TIMBAD 评分都要有一个具体证据；L4–L7 尤其要指出核心认知障碍和为什么不是相邻等级。

# 2. 依据：TIMBAD 原始定义

**直接依据**：用户上传的《Timbad_and_FMA_Dynamics_Force_Analysis.pdf》，PDF **第 1 页**《Timbad Problem-Solving Framework》，以及第 2 页《Newton's Laws: FBD Workflow》。以下名称和任务保留源文件原意；难度评分细则和数据字段为本文增订。

| 字母 | 原始名称 | 原框架要求解决的事 | 转化为评级时的问题 |
|---|---|---|---|
| **T** | **TARGET** | 明确所求物理量、物体/系统、方向/正负、时刻/状态、平衡或释放条件 | **确定精确求解目标有多难？** |
| **I** | **INFORMATION** | 提取已知量、几何、初末状态；将 smooth、taut、equilibrium、released from rest 等语言转换成物理条件 | **发现并正确解释有效信息有多难？** |
| **M** | **MODEL** | 选择与目标关联的质点/刚体模型、牛顿定律或能量/动量方法；选择研究对象、参考系与假设 | **选择或构建适当物理模型有多难？** |
| **B** | **BRIDGE** | 从目标反推已知量；用规律、定义、几何、约束或守恒串联；清点未知量与独立方程 | **搭建从已知到目标的关键联系有多难？** |
| **A** | **ANALYZE** | 使用代数、微积分、矢量、三角函数、近似等工具，必要时先保留符号 | **完成数学处理需要多强的推导与技巧？** |
| **D** | **DOUBLE CHECK** | 事前使用极限情况预测；事后检查方向、符号、大小、单位、假设和约束，失败则回溯 | **判定结果物理有效性需要多复杂的检验？** |

第 2 页的 FBD 流程可与 TIMBAD 对齐：选择系统与外部相互作用（M/I）、画 FBD 与选择坐标轴（M）、建立方程与加入摩擦/绳长/无滑动等约束（B/I）、求解并验证（A/D）。**不要另创与这份原始框架冲突的步骤。**

# 3. 先审核题目质量：L0 与信息不足

**质量审核先于难度审核。** `L0 = Rejected` 是题库筛除状态，不参与 L1–L7 难度序列。

## 3.1 判为 L0 的条件

在确认问题后无法以合理方式修复，或者作为独立题目缺乏任何增量教学价值时，可判为 L0。必须记录具体原因码：

| 原因码 | 含义 | 处理 |
|---|---|---|
| `FATAL_PHYSICS_ERROR` | 物理规律或答案存在不可接受的根本错误 | L0，附解释 |
| `UNDERDETERMINED` | 关键条件缺失、存在多个不等价解，且无法通过合理常规假设补足 | L0，指出缺失条件 |
| `AMBIGUOUS_UNFIXABLE` | 存在不可消除的实质性歧义 | L0，指出不同解释 |
| `OUT_OF_SCOPE` | 与题库预定教学范围无关、无独立训练目标 | L0，说明范围 |
| `DUPLICATE_NO_ADDED_VALUE` | 已收录完全等价题目，且这个**副本**没有新用途 | 将副本 L0/归档；**不**否定原题价值 |
| `MISLEADING_HARMFUL` | 设计会系统性教错物理，不能简单更正 | L0，说明问题 |

**不能仅因为题目“太简单、纯概念、没有计算、来自 IGCSE、没用高级数学”而判 L0。** 很多 L1 题具有重要的诊断价值。

## 3.2 需要修订 ≠ L0；材料不完整 ≠ L0

- `REVISE`：小范围更正表述、数值、图示即可保留教学价值；可以在充分可靠时给出**暂定难度**。
- `NEEDS_REVIEW`：图片未提供/模糊、选项缺失、必要条件无法读取、解题结论不确定；**`overall_level = null`，TIMBAD 可全部为 null**，不得臆造内容或将其误判为 L0。
- `APPROVED`：题目可正常使用，已达到本规范的审核要求。
- `REJECTED`：确认 L0。

`overall_level = "L0"` **当且仅当** `review_status = "REJECTED"`。`NEEDS_REVIEW` 不允许强行给 L1–L7。

## 3.3 验证质量时检查

文字、单位、数值、图像是否完整；假设是否足以支持所求量；有无多个正确选项；题目的“正确答案”是否真的满足全部物理约束；版本/图像裁剪是否导致条件丢失；是否存在纯粹排版错误。可修订题应将**原题评级**与**修订后评级**分开。

# 4. TIMBAD 六维评分量表：0–2

每一维使用共同刻度：

- `0 = Direct / 直接`：几乎不需要该维度上的主动策略；或这一步无实质困难。
- `1 = Moderate / 常规分析`：需要主动判断、转换或串联，但使用熟悉方法即可完成。
- `2 = Challenging / 非显然`：存在需要主动发现的隐含关系、非标准选择或较高推理/数学技巧要求。

**评分必须基于完整题目和可行解法，不得以“看着复杂”评分。** 0 不是该物理环节不存在，而是其难度较低。每项记录 `score`、`rationale`（评分理由）以及尽量明确的 `evidence`（题目条件或解题步骤）。

## 4.1 T — Target Difficulty（目标识别）

**问题**：学生要确定“到底求谁、求什么、何时求、沿什么方向、在哪种状态下求”，需要多少物理判断？

| 分数 | 可执行标准 | 正例 |
|---|---|---|
| **T0** | 目标变量、对象与状态明确，无需转换 | “求此物块的加速度大小” |
| **T1** | 需澄清作用对象、符号、参考系，或把描述转换为一个熟悉的可计算目标 | “求人对秤的力”；区别于“秤对人的力” |
| **T2** | 需要自行定义决定成败的中间目标、临界状态或等价目标；仅照字面直接计算会偏题 | “何时失去接触？”必须识别临界条件（如 `N = 0`）并确定对应状态 |

**边界**：如果已经清楚要找什么，但不知道用什么模型，是 **M**，不是 T；如果题目语病造成难懂，是质量问题，不能给 T2 当作奖励。

## 4.2 I — Information Difficulty（信息解码）

**问题**：将文字、数据、图像和隐含条件准确转成物理量/约束有多难？

| 分数 | 可执行标准 | 正例 |
|---|---|---|
| **I0** | 数值、初末状态、几何直接给出 | “质量 2 kg，受力 6 N” |
| **I1** | 需识别一个熟悉的隐含条件、读图关系或语言提示 | “released from rest → `v0 = 0`”；“constant speed → 切向加速度为 0（仍可能有法向加速度）” |
| **I2** | 多个条件相互制约，或存在一个易错而至关重要的非显然信息转换 | 弹簧连接系统突然切断支撑的**瞬间**，有限刚度理想弹簧形变与张力不突变 |

**边界**：条件已被正确识别，仍不会建立方程，是 **B**；初始状态的信息提取不等于后续数学推导。I2 不必然达到 L5，应考虑这一条件在当前前置知识中是否常规。

## 4.3 M — Model Difficulty（模型选择与建构）

**问题**：选哪个研究对象、分离/合并哪些物体、采用什么定律、参考系或近似模型，有多困难？

| 分数 | 可执行标准 | 正例 |
|---|---|---|
| **M0** | 模型明确、直接 | 直接用 `ΣF = ma` |
| **M1** | 需主动选择、比较或组合常规模型 | 选整体法还是隔离法；摩擦斜面上的惯性参考系、FBD |
| **M2** | 需要非标准等效、精巧的系统划分/参考系，或改变通常的模型表达，才能找到有效路线 | 将传送带滑动问题改写为**相对传送带的运动**；构建非标准约束系统 |

**边界**：仅多画几张 FBD 并不自动 M2；如果模型已明显，困难在新增未知量之间缺少方程，是 **B**。使用“质点/刚体”是知识内容，不自动升难度。

## 4.4 B — Bridge Difficulty（搭建物理联系）

**问题**：从目标反推，学生能否将已知量、力学定律、几何、约束或守恒原则连成完整可求解的方程链？

| 分数 | 可执行标准 | 正例 |
|---|---|---|
| **B0** | 单条直接联系；已知与目标距离近 | `a = F/m` |
| **B1** | 需多个**熟悉且逻辑关联**的式子、正常联立或常规约束 | 对两物体分别列 `ΣF = ma`，并用已知共同加速度关系联立 |
| **B2** | 某个决定性联系不是题目或常规套路直接给出的；需要自行发现或推导 | 自行导出隐藏绳长约束；发现可用于求目标的非显然守恒/对称关系 |

**边界**：B2 不是“方程超过三条”。很多方程机械联立可以仍为 B1；**真正稀缺的是找到缺失的连接环节**。

## 4.5 A — Analyze Difficulty（数学分析与求解）

**问题**：在物理方程已经建立后，完成数学求解还有多难？

| 分数 | 可执行标准 | 正例 |
|---|---|---|
| **A0** | 直接代入、单次变形、常见计算（包括已熟悉的简单求导） | 解 `ma = F`；直接解一元线性式 |
| **A1** | 需要较长但标准的代数、三角、矢量、常规微积分、最优化或联立步骤 | 用 `sin 2θ = 2 sinθ cosθ` 简化并找极值 |
| **A2** | 数学本身需要非显然策略或较难构造，即使物理模型已给出依然明显困难 | 巧妙非标准代换、困难积分、复杂三维几何/渐近展开、非标准微分方程求解 |

### `A` 评分与 `math_tools` 必须分开

- `A` 衡量**使用数学工具的推理与技巧难度**。
- `math_tools` 记录**用到了什么数学工具及其先修知识**。
- 例如，熟悉简谐振动常规微分方程的学生直接识别标准形式，可以 `A0/A1 + Differential Equations`；一道精巧初等几何题可 `A2 + Trigonometry/Geometry`。
- 高阶数学作为必需**知识门槛**时，应体现在 `prerequisites` / `math_tools`，**不能自动**把题目提升到 L6/L7。

## 4.6 D — Double Check Difficulty（物理检验）

**问题**：确认所求结果满足物理规律、边界和假设，需要多少主动判断？

| 分数 | 可执行标准 | 正例 |
|---|---|---|
| **D0** | 常规量纲、正负号、数量级、简单合理性检查 | 检查 `a` 的单位是 `m/s²` |
| **D1** | 需要检验某个非平凡的极限、方向或模型适用条件 | `μ → 0` 后结果应与无摩擦情形相符 |
| **D2** | 多种状态/数学根/分支，必须完成实质性物理有效性判别 | 求得代数解后仍需验证是否保持接触、是否满足静摩擦上限、绳子是否真的绷紧 |

**特别规则**：D 不是“题目有没有需要检查”。所有题都应 Double Check。只有检查过程本身增加实质认知要求才给 D1/D2。**同一个临界条件若既用于建模也用于验证，不可在整体等级中重复加难度。**

# 5. 整体难度：L1–L7

> `overall_level` **不是** TIMBAD 六维分数的和。先依据下表直接定级，再用六维画像说明依据；有分歧时进入 §6 的对照审查。

| 等级 | 标准名称 | 决定性判断 | 典型解题路径（非硬性条件） |
|---|---|---|---|
| **L1** | Fundamental / 基础概念 | 基本识记、识别或单一概念直接理解 | 不需建立实质的推导链 |
| **L2** | Direct Application / 直接应用 | 目标与方法高度明显，使用熟悉规律即得答案 | 直接代入或简短标准应用 |
| **L3** | Standard Problem Solving / 常规综合 | 需要独立组织多个关联步骤，但核心策略属于标准已学方法 | 常规 FBD → 分解 → 建式 → 求解 |
| **L4** | Advanced Problem Solving / 高阶综合 | 多模型/多状态/复杂条件的常规方法组合；需要审慎选择策略，但**没有特别突出的非套路化核心洞察** | 复杂标准建模、分段分析、联立限制条件 |
| **L5** | Introductory Competition / 竞赛入门 | 存在一个**实质性的非显然关键突破点**；发现之后通常可沿相对常规方法收尾 | 隐含等效模型、巧妙约束、关键状态转换、数学技巧 |
| **L6** | Advanced Competition / 高阶竞赛 | 需要**深入的非标准推理**；即使给予第一个局部突破提示，仍有较大的独立推理障碍 | 深度建模、连续多段非常规联系或难度很高的单一核心构造 |
| **L7** | Elite Olympiad / 顶尖竞赛 | 需要**高度创造性**的建模、物理洞察或严密论证，明显超出常规竞赛套路 | 多重深刻突破；或一个极难发现且必须严密展开的原创性突破 |

## 5.1 两条最重要的边界

- **L4 vs L5**：主要障碍是**熟悉方法的复杂组合**（L4），还是**必须主动发现一个实质性非套路思路**（L5）？不能单靠题干长短、计算量或有无多个状态判断。
- **L5 vs L6**：若给予**一个局部且不泄露全部解法的关键提示**，后续是否基本能用标准流程完成？能，通常 L5；仍需要深入探索、发现额外重大联系，通常 L6。
- **L6 vs L7**：是否要求超出已有竞赛套路的高度创造性组织？多个非显然突破点常支持 L7，但**突破点数量不是硬阈值**；一个异常深刻的构造也可能是 L7。

## 5.2 强制的“反面判据”

- 一题包含 **10 个代数步骤**，不能仅此定为 L5。
- 一题采用**微积分/微分方程**，不能仅此定为 L6。
- 一题出处是 **F=ma/BPhO**，不能仅此定为 L5+。
- 一题使用**一个非标准想法**，不必然 L5：如果它在该题设定的正常前置训练中已成为标准方法，可能是 L3/L4。
- 高阶竞赛题不要求每个 TIMBAD 维度都高分；**一项深刻障碍**有时足以决定等级。
- `L7` 要谨慎使用，说明**超出 L6 的具体创造性障碍**；不能只写“非常难”。

# 6. 六维画像与整体等级如何结合

## 6.1 严禁简单相加

`T + I + M + B + A + D` 可以做内部描述性统计，但**不允许作为计算 L 的公式**，原因是维度之间相关，同一解题障碍可能同时表现为 I2、M2、B2。`D` 常为结果验证，也不应机械再加一次。

示例：

- `T2 I2 M0 B0 A0 D0`：澄清语言与状态不易，但物理运算直接，不必然是竞赛题。
- `T0 I0 M2 B2 A0 D0`：题目条件直接，但非标准模型和核心联系难发现，可以是 L5/L6。

## 6.2 推荐的逐级决策树

1. **质量可用吗？** 否且确认无法保留 → L0；材料不足 → `NEEDS_REVIEW, level=null`。
2. **是否主要是记忆/概念识别？** 是 → L1。
3. **是否直接使用熟悉公式或关系，几乎无独立策略选择？** 是 → L2。
4. **需要多个环节，但解题方法完全标准且相对明确？** 是 → L3。
5. **需要复杂状态判断、多条方程或模型组合，但仍是已知标准策略组合？** 是 → L4。
6. **是否存在必须独立发现的实质性非显然关系、模型转换或数学构造？** 否 → 优先 L3/L4；是 → 至少进入 L5 候选。
7. **一个恰当的局部提示是否基本解除主要障碍？** 是 → L5 候选；否 → 考虑 L6。
8. **是否仍涉及高创造性、多重深度突破，或一个异常深刻突破？** 是且有明确证据 → L7；否则 L6。

以上是**默认顺序**，不是数学上绝对的门槛。极少数非常难的纯数学物理题，也可能因 A2 中极高深度的原创性分析进入高等级，须说明原因。

## 6.3 “提示测试”如何正确实施

提出**一个不会直接给出答案**的局部提示，例如“尝试在传送带参考系观察相对速度”，而非“相对速度初值是 `√2v`，所以选 C”。再判断：

- 没有任何关键提示也能走标准流程：L3/L4。
- 一条恰当的提示几乎打开全题：常是 L5。
- 第一条提示之后仍需非标准发现：常是 L6。
- 需要多重高度创造性发现：考虑 L7。

提示测试是辅助，不是让 AI 实际与学生交互的强制步骤，也不能由“专家觉得一句话很简单”取代前置知识参照。

## 6.4 突破点与难度的关系

保存两个字段：

- `key_insights`: 解题必须独立发现的关键非显然关系，**逐条简短描述**；无则 `[]`。
- `insight_depth`: `NONE | MODEST | SUBSTANTIAL | DEEP | EXCEPTIONAL`（无、较浅、实质性、深、极深）。

`key_insight_count = len(key_insights)`；“突破点数量”不能直接决定 L。**不要把每个公式或算术步骤都列作突破点。**

## 6.5 给每道题最多两个主要障碍

- `primary_bottleneck`：`T | I | M | B | A | D | NONE` 中**必须选择一个**，仅真正 L1 或无显著障碍时可填 `NONE`。
- `secondary_bottleneck`：`T | I | M | B | A | D | NONE`，可填 `NONE`，不应与 primary 相同。
- `primary_bottleneck` 不一定等于唯一的最大分数；如果两个维度并列 2，选择**最先阻断独立求解**且最具有训练价值的环节，并在理由中说明。

## 6.6 避免在 TIMBAD 间重复计算相同难点

| 看到的困难 | 主要归属 | 次要归属的条件 |
|---|---|---|
| 不懂“求谁对谁的力” | T | B：还需链接牛顿第三定律 |
| 漏读“just after release”与初态 | I | T：题目还需重新界定时刻 |
| 不知道用相对运动还是地面系 | M | B：选模型后仍要建关键关系 |
| 明知模型，但缺少绳长约束方程 | B | I：绳长条件本身也隐藏或难提取 |
| 式子列对却不会积分、代换、优化 | A | B：只有物理关系本身也非显然时 |
| 方程解出来但不满足接触/静摩擦条件 | D | M/B：该约束是建立解法的核心条件时 |

**六维允许多个高分；但写整体等级理由时，同一个障碍只能算一次。**

# 7. 逐题标准操作流程 SOP

对**每一道完整的题目**严格执行以下顺序：

### Step 0 — 锁定题目与审核范围

保存 `question_id`、出处、年份、原题号、题干、全部图/表/选项/小问、单位、必要假设。确认审核对象是单一小问还是一个多问组合。**不得根据未见到的图猜测条件。**

### Step 1 — 质量门控

检查是否可解、图像是否齐全、选项有无矛盾、是否缺关键前提。给 `review_status`：`APPROVED / REVISE / NEEDS_REVIEW / REJECTED`。`REJECTED` 输出 L0 与原因；`NEEDS_REVIEW` 的等级及六维允许/建议为 `null` 并解释缺口。

### Step 2 — 独立解题（必须发生在最终评分之前）

按原始 TIMBAD 的内容记录一条足够可靠的**简要解题链**：

1. **T**：目标变量、对应对象、参考系/正负、时刻/状态。
2. **I**：给定量、隐含条件、几何/图像信息、初末状态。
3. **M**：选定系统、作用力、模型、参考系、适用假设。
4. **B**：从目标回推，写出关键联系、方程、守恒或约束；必要时未知数/独立方程清点。
5. **A**：完成必要数学过程并确认结果或正确选项。
6. **D**：验证单位、方向、边界、假设、接触、摩擦、绳长等。

记录 `solution_outline`、`final_answer`；如果无法可靠求解而题目本身看似合理，**不要虚构最终答案/难度**，标 `NEEDS_REVIEW`。

### Step 3 — 给 TIMBAD 六维评分

每项按照 §4 独立评分 `0/1/2`，附**至少一条具体依据**。即使 0 分，也用简短说明“为何直接”。分数解释必须对应该维度，不能把“总体难”重复贴六次。

### Step 4 — 识别核心突破点和瓶颈

列出 `key_insights`（不含机械计算）；给 `insight_depth`、`primary_bottleneck`、`secondary_bottleneck`。若确无突破点，写 `[]` 和 `NONE`，不要硬造。

### Step 5 — 给总体 L1–L7

依 §5/§6 直接做整体判断，**不对六维求和**。尤其 L4–L7，要写：

- `overall_reason`：本题为什么属于这个等级，引用解题链中的事实。
- `boundary_reason`：为什么不应划入更低或更高的相邻等级（如 L4 vs L5、L5 vs L6）。
- `rating_confidence`：`HIGH | MEDIUM | LOW`；`LOW` 建议人工复核。

### Step 6 — 赋予教学与数学标签

填写章节、子专题、前置知识、训练技能、数学工具、可选学习用途和建议完成时间。**不得因缺少来源、预计时间而臆造数值**；未知值用 `null` 或 `[]`。

### Step 7 — 一致性检查并输出

核查：题目是否真的解出；选项/单位是否一致；各维度理由是否贴合；整体 L 与突破点深度是否矛盾；图像不全时有没有乱猜；结构化数据类型是否合法；是否需要交人工复核。

# 9. 多问题、缺失图片、歧义与替代解法

## 9.1 多个小问

- **默认先逐小问评级**：`part_a: L2`, `part_b: L4` 等，各自有 TIMBAD 画像。
- 若必须给整道复合题一个整体级别：建议取其**最高实质认知要求**作为基准，不因包含多个小问就机械提高一级。
- 如果多问之间产生新的、必须统筹的复杂依赖关系，可以提高整体评级，但必须证明出现了额外的非标准推理障碍。
- 如果用户只要求审核某一个小问，不能把其他小问的困难算进去。

## 9.2 图像/题干不完整

- 缺少决定解法的图形、坐标约定或选项 → `NEEDS_REVIEW`，`overall_level=null`，在 `review_notes` 写明缺失信息。
- 不得仅凭“常见题型”猜图后评分；不得用文字提到“如图所示”就默认看到了图。
- 可能存在多种图像解释时，先请求核实；无法核实时不上线题库。

## 9.3 意义上的歧义

- 两个合理解释产生不同物理答案：标注歧义；可修则 `REVISE`，不可修则 `REJECTED/L0`。
- 正常需要学生识别的物理条件（如静摩擦为不等式）不是质量歧义。

## 9.4 解题路径不唯一

- 分别识别可行路径是否需要不同的 `M/B/A` 技巧。
- 以**课程先修范围内相对合理可发现的最简可靠路径**定整体难度；备选路径可在 `review_notes` 说明。
- 不因为存在一个需要竞赛妙招的可选解，就把常规可解的题强行评为 L5+。
- 但若唯一明显的捷径极难独立发现，而常规路径虽可行却同样存在严重障碍，不能过分降低评级。

## 9.5 题目存在物理边界/参数分段

- 是否需要验证静摩擦 `|f_s| ≤ μ_s N`、接触 `N ≥ 0`、绳子张力/松弛、速度方向改变、有效参数范围等，必须在解题中处理。
- **不要仅因为存在这些名词就给 D2**：要看题目是否要求实质性筛选有效解。

## 9.6 课程体系与数学先修

跨课程评级的假设是相关前置知识已掌握。可用 `prerequisites` 和 `math_tools` 进一步定义门槛。学生实际尚未学习这些知识，属于作业适配问题，不是题目的整体难度应变高。

# 10. 真实题目审核示例及锚定题

> 这些示例取自用户上传的《Timbad_and_FMA_Dynamics_Force_Analysis.pdf》，**题号为该 PDF 后半部分的练习题号**，不是 PDF 页码。以下 L 与 TIMBAD 分数是本规范的**初始人工锚定示例**，尚未经独立审核员一致性测试；遇到定义边界变化，可以修订并记录原因。**未实际出现的 L6/L7 真题锚点不能伪造。**

| 题目 | 题意/主要思路 | 初始 L | T | I | M | B | A | D | 主要瓶颈 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---|
| Q1（PDF p.3） | 加速飞船中的宇航员**对飞船**的力；辨认作用对象并用第三定律 | **L2** | 1 | 0 | 0 | 1 | 0 | 0 | T |
| Q4（PDF p.5） | 人站体重秤并抬起书本；推断读数变化的可能曲线 | **L4（边界 L3）** | 1 | 1 | 1 | 1 | 0 | 1 | M |
| Q12（PDF p.10） | 水平投影长度固定的斜面，求最短滑行时间的倾角 | **L4（边界 L3）** | 0 | 1 | 1 | 1 | 1 | 1 | B |
| Q27（PDF p.18） | 连接两物体的弹性绳，上端突被剪断；求**剪断瞬间**加速度 | **L5（边界 L4）** | 1 | 2 | 1 | 2 | 0 | 1 | I |
| Q28（PDF p.19） | 传送带向东、物块向南，问何时不再相对滑动 | **L5（边界 L4）** | 1 | 1 | 2 | 2 | 1 | 1 | M |

### 10.1 锚点：Q1（L2）

- **T**：问的是宇航员**对飞船**的力，需要确认与飞船对人的法向力是一对第三定律作用力 → `T1`。
- **I/M**：质量、加速度直接给定，质点模型明确 → `I0/M0`。
- **B**：由人的受力方程求法向力，再由第三定律得到所求力 → `B1`。
- **A/D**：简单代数与单位、方向核查 → `A0/D0`。
- **总体**：虽然 Target 存在易错点，仍以熟悉物理规律直接求解为主；不升级到 L3。

### 10.2 锚点：Q12（L4/L3 边界）

题目中斜面**水平长度** `L` 固定，不是斜面长度固定。核心步骤：

1. `s = L / cosθ`；斜面加速度 `a = g sinθ`。
2. `s = at²/2` → `t² = 2L/(g sinθ cosθ) = 4L/(g sin2θ)`。
3. 需最大化 `sin2θ` → `θ = 45°`，且应位于 `(0°,90°)` 区间。

- `B1`：需要连接几何距离、运动学和角度关系。
- `A1`：需要标准三角恒等式/优化。
- `D1`：核对极限角 `θ→0°,90°` 时相应时间趋势。
- 初步 L4 是因为此处要求独立识别“水平投影不等于运动路径”，并组织物理—几何—优化链；如果既有锚定题将它判为典型的标准综合训练，也可降到 L3。**这是边界例，不宜用于单独定义 L4 的阈值。**

### 10.3 锚点：Q27（L5/L4 边界）

核心突破：**剪断上方弹性绳的瞬间，下面弹性绳的长度不能瞬时改变，故其初始张力不突变**（理想弹性模型及有限速度变化假设下）。继而分别隔离上下物体用牛顿第二定律。

- `I2`：识别“刚剪断的瞬间”不是“已经运动一段时间后”。
- `B2`：将剪断前平衡时求得的弹性绳张力直接作为剪断后的瞬时受力联系。
- `A0`：剩下只是加减与 `F=ma`。
- **何以可为 L5**：若学生只熟悉静态受力/普通绳子，必须发现这个瞬时连续性关系才能起步；提示这一点后可常规求解。
- **何时降为 L4**：若题库面向的预期先修中“瞬间形变量不突变”已是高度熟悉的标准套路，应按训练基准复核。

### 10.4 锚点：Q28（L5/L4 边界）

关键是将 Target 识别为**停止相对滑动**，并在**相对传送带**的速度空间内讨论摩擦减速：

- 初始相对速度大小：`|v_rel,0| = √(v²+v²) = √2·v`。
- 在水平、恒定法向力、动摩擦系数 `μ` 且传送带速度恒定的理想模型下，摩擦加速度大小为 `μg`，方向反对相对滑动，因此 `t = √2·v/(μg)`。
- `M2`：选择相对运动的描述显著简化问题。
- `B2`：从“相对滑动停止”转换为“相对速度减至零”建立关键联系。
- `A1`：基本矢量速度差与标量关系；不要求高级数学。
- 初始判断为 L5，前提是相对运动的方向处理并非当前标准题型；若该学生群体常规训练已覆盖这种典型速度差计算，评为 L4 也可以。

### 10.5 L1、L3、L6、L7 未来锚定要求

为每级收集 **5–10 道真实题目**，力学、电磁、热学等尽量覆盖；必须附完整图、正确答案、TIMBAD 画像和等级理由。当前 PDF 中上表提供了部分 L2/L4/L5 的候选，但**不能据此声称已完成 L1–L7 全覆盖校准**。

- **L1 仅作说明（非此 PDF 真题）**：“What is the SI unit of force?” → L1。
- **L3 仅作说明**：标准斜面受力分析，多步且无隐藏创造性模型 → 典型 L3（在具体图与条件确认后评级）。
- **L6、L7**：必须以后选取实际 F=ma/BPhO 等试题核准。不能写一个笼统的“超难滑轮题”就当成已验证锚点。

# 11. AI 的固定输出格式与 JSON 示例

## 11.1 每题先输出精简阅读版

```text
Question ID: MEC-FTS-0028
Review Status: APPROVED
Overall Difficulty: L5 (Introductory Competition)
TIMBAD: T1–I1–M2–B2–A1–D1
Primary Bottleneck: M (Model)
Secondary Bottleneck: B (Bridge)
Key Insight: 用相对传送带的速度判断滑动终止条件。
Math Tools: Vectors, Algebra
Core Reason: 必须主动识别相对运动模型；找到该模型后可用常规矢量关系与匀减速计算求解。
Boundary: 比 L4 更偏向一个非显然模型转换；提供“用相对速度”提示后，后续求解比较直接，不到 L6。
Confidence: MEDIUM
```

**此后必须附结构化 JSON。** 一个合格答案不应只给 `L5`，却没有解题依据、六维评分或瓶颈标签。

## 11.2 JSON 数据契约

- 所有 `score` 只能为**整数** `0,1,2`；材料不足时为 `null`，不得用 1.5、"中等" 或字符串 "2"。
- `overall_level` 只能为 `L0,L1,L2,L3,L4,L5,L6,L7,null`。
- `rating_confidence` 只能为 `HIGH, MEDIUM, LOW`。
- 日期为 ISO 8601；不确定则 `null`。
- 字段名固定为英文 snake_case；评价文字用中文（必要的物理量及符号可用英文/LaTeX）。
- 无来源、无用时统计，不得编造具体年份、预计分钟、错误率和选项。
- 若 `review_status = REJECTED`：`overall_level = L0`，`rejection_reason` 非空，TIMBAD 评分可用 `null`。
- 若 `review_status = NEEDS_REVIEW`：`overall_level = null`，解释 `review_notes`，不可强行给分。
- 若 `review_status = APPROVED`：六维分数、整体等级、完整题意与解题链必须有足够依据。

### 11.3 校验规则（写入审核程序更好）

1. `timbad` 必须恰好有 `T,I,M,B,A,D` 六项。
2. 完整审核时各 `score` 为 0/1/2，且每项有非空 `rationale`。
3. `primary_bottleneck`、`secondary_bottleneck` 只能取六个字母或 `NONE`；若二者非 `NONE`，不能相同。

8. `review_status` 与 `overall_level` 的 L0/null 关系必须满足 §3。
9. 与锚定题评级相差 2 级或更多且无清晰理由时，自动触发 `needs_human_review=true`。

# 12. 可直接复用的 AI 审核提示词

> 下列提示词可作为批量审核时的系统指令或任务说明。**必须同时向 AI 提供本 MD 文件全文，以及每道题的完整题干、图表和选项。** 只给一个文件名、不提供文件内容，不足以保证 AI 真的执行规范。

```text
你是 Pocket Cosmos 物理题库的专业审核员。请严格按照随附的
《Pocket Cosmos — TIMBAD 物理题库评级与审核规范 v1.0》审核题目。

任务：对每一道题独立完成质量门控、TIMBAD 解题、六维评分、
整体 L0–L7 评级、训练技能标注及结构化 JSON 输出。

硬性规则：
1. 不根据考试来源、题干长度、纯计算量、涉及微积分与否推断难度。
2. 假设学生已学过必要前置知识及常规方法，但未见过该具体题目。
3. 先解题并核对关键物理约束，再评级；不允许先猜 L 再补理由。
4. T/I/M/B/A/D 六维分别按 0–2 评分，并为每一项说明具体证据。
5. 整体 L0–L7 直接根据认知门槛、非显然关系深度和解题路径决定，
   禁止对六维分数简单加总。
6. 对 L4–L7，必须交代为什么不是上下相邻级别，尤其区分：
   L4=复杂标准方法组合；L5=实质非显然突破；
   L6=深入非标准推理；L7=高度创造性突破。
7. 区分题目难度与学生错误；区分数学工具与数学难度。
8. 看不到关键图像、题干不完整、无法验证解法时，输出 NEEDS_REVIEW；
   不得脑补条件；不确定时降低 confidence 并标记人工复核。
9. 每道题先输出精简阅读版，再输出一个合法 JSON 对象，字段按规范 §11。
10. 批量审核时每题必须分别输出；不要因相似来源或相邻题号批量套用评分。

输入：题目完整文本、全部图像与选项、题号及已验证来源（若有）。
输出：一题一份审查结果，不得跳过任何必填字段。
```

### 批量任务的额外要求

- 一次处理 N 题时，使用稳定的 `question_id`，**每题独立分析和评分**。
- 题目疑似重复，只记录疑点、检查已收录的 canonical ID；未核实前不可盲判 L0。
- 若用户只给 PDF 的某些页，确认题目是否跨页，避免漏掉图或后一页的附加条件。
- 如需批量数据导入，可输出 JSONL：一行一个 §11 的 JSON 对象；保持每道题对应的一条记录，不得混写解释段落。
- 批量任务完成时再汇总“各 L 数量、各瓶颈分布、待人工复核数”；**不能为了分布好看而修改单题等级**。

# 13. 人工复核、版本管理与校准

## 13.1 何时必须人工复核

- `rating_confidence = LOW`。
- L4/L5 或 L6/L7 边界难以稳定判断。
- 只依赖某一种少见解法才能得到等级。
- 题目可能存在实质性多解、物理模型不自洽、图像关键区域不清楚。
- 与相似锚定题等级差异大，或者两个独立审核员评级相差 **2 级及以上**。
- 确认需要 L7，但无法明确说明特别深刻的突破点。

## 13.2 锚定与一致性测试

1. 每个等级积累 **5–10 道**高质量锚定题，包含完整题、标准解、六维画像、L 评级和“与邻级区别”。
2. 至少两位审核员（可为人工与 AI）独立盲评相同题目，比较整体 L、六维及核心障碍。
3. 讨论不一致原因，优先修改**规则解释或锚定题**，而不是为了统一结果随意改分。
4. 每季度/每增加一批有代表性的新题后，抽样复评，监测相同题在不同时间/模型上的稳定性。
5. 留存 `rubric_version`、`rating_confidence`、`reviewer` 和复核决定；评分变更必须可追溯。

## 13.3 利用真实学生数据校准（不是简单按正确率改 L）

可另存：`student_id`、知识已学状态、是否独立完成、是否使用提示、完成时间、错误 TIMBAD 标签、题目正确率。数据不足时不要假装有统计显著性。作答正确率受学生水平、先修知识、提示、课堂训练与题目本身共同影响，因此不能直接把“70% 的人做错”翻译为 L6。**统一题目难度标签保留，学生个体适配另建模型。**

## 13.4 版本规则

- 小修（如表述澄清，`1.0 → 1.0.1`）：不改等级概念。
- 大修（例如重新定义 L5/L6 或六维阈值，`1.x → 2.0`）：需要标识旧题按旧版本评级，必要时重新审核锚定集。
- 已审核题的数据始终保留 `rubric_version`，便于回溯。

# 14. 审核清单与常见误判

## 14.1 每题交付前逐项自检

- [ ] 题干、关键图片、选项、小问完整；否则已标 `NEEDS_REVIEW`。
- [ ] 判断了质量：`APPROVED / REVISE / NEEDS_REVIEW / REJECTED`。
- [ ] 至少有一条足够可靠的 TIMBAD 解题链，并核对关键结果。
- [ ] 六维 T/I/M/B/A/D 分数均为 0–2，理由有具体证据。
- [ ] 整体等级按 L 定义判定，没有计算六维总分。
- [ ] 若为 L4–L7，说明了关键难点及相邻级别界限。
- [ ] `primary_bottleneck` 与必要的 `secondary_bottleneck` 已标明。
- [ ] `math_tools` 与 `A` 的含义没有混淆。
- [ ] 题目难度与学生个人错误没有混淆。
- [ ] 所有缺失字段都用 null/空数组，不编造年份、图示或耗时。
- [ ] JSON 类型、枚举与 L0/缺失资料逻辑正确。

## 14.2 高频误判对照

| 错误做法 | 正确做法 |
|---|---|
| “BPhO 所以 L6” | 解题、识别隐藏关系与认知门槛后评级 |
| “积分题所以 A2/L6” | 数学知识放 `math_tools`；数学技巧难度放 A |
| “方程多，所以 B2/L5” | 判断是否有**非显然**连接，而不数方程条数 |
| “读题绕，所以 T2” | 先排查是否属于糟糕措辞或关键条件缺失 |
| “同一条件影响 I/B/D，三项加起来就是 L7” | 六维均可记录，但整体只认定一次核心障碍 |
| “不会做，所以 L7” | 无法可靠建立解法 → 待复核，不得以不确定性伪装为高难 |
| “太简单，扔进 L0” | 有教学价值的简单题是 L1/L2；L0 仅淘汰 |
| “大多数学生做错，所以改成 L6” | 先确认学生基础、是否学过、题目质量和有效样本 |
| “画着很多滑轮，所以 M2” | 查找真正的模型选择难点；复杂外观不足以升分 |
| “题中有临界条件，所以 D2” | 看是否需实质性的物理有效性验证 |

## 一分钟速查卡（Reviewer Quick Reference）

**先质量门控**：无效/无保留价值 = **L0**；材料缺失 = **NEEDS_REVIEW，不强行给 L**。

**总体等级**：

- **L1** 概念识别；**L2** 直接应用；**L3** 常规多步；**L4** 复杂标准综合；
- **L5** 实质性非显然突破；**L6** 深入非标准推理；**L7** 高度创造性突破。

**TIMBAD 画像**：

- **T**：找到精确 Target 难不难？
- **I**：从文字、图表提取隐含信息难不难？
- **M**：选择/建立物理模型难不难？
- **B**：从已知连接到目标的关键关系难不难？
- **A**：数学处理本身难不难？
- **D**：验证物理有效性、边界与极限难不难？

六维各用 **0 = 直接 / 1 = 常规分析 / 2 = 非显然**；**不求和**。

**每题完整输出至少包括**：`overall_level`、`T/I/M/B/A/D`、`primary_bottleneck`、`key_insights`、`math_tools`、`key_skills`、`topic/subtopic`、`solution_outline`、`overall_reason`、`boundary_reason`、`rating_confidence`、`review_status`。
